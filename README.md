# codex-first-step

이 저장소는 아주 간단한 파이썬 예제입니다.

## 1) 준비하기
1. 컴퓨터에 Python이 설치되어 있는지 확인합니다.
2. 터미널(또는 명령 프롬프트)을 엽니다.
3. 이 프로젝트 폴더로 이동합니다.

## 2) hello.py 실행하기
`hello.py` 파일은 `Hello, Codex!`를 화면에 출력합니다.

### Windows
1. `Win + R` 키를 누르고 `cmd`를 입력한 뒤 Enter를 누릅니다.
2. 프로젝트 폴더로 이동합니다.
   ```bat
   cd 경로\codex-first-step
   ```
3. 아래 명령어를 실행합니다.
   ```bat
   python hello.py
   ```
4. 화면에 `Hello, Codex!`가 보이면 성공입니다.

### macOS
1. `Command + Space`를 누르고 `Terminal`을 검색해 실행합니다.
2. 프로젝트 폴더로 이동합니다.
   ```bash
   cd /경로/codex-first-step
   ```
3. 아래 명령어를 실행합니다.
   ```bash
   python3 hello.py
   ```
4. 화면에 `Hello, Codex!`가 보이면 성공입니다.

## 3) 문제 해결 (처음 배우는 분용)
- `python` 또는 `python3` 명령어가 없다고 나오면 Python 설치가 필요합니다.
- 폴더 이동(`cd`)이 어렵다면, 폴더를 터미널 창으로 끌어다 놓아 경로를 자동 입력할 수 있습니다.
